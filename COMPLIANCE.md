# Compliance Boundary

This repository demonstrates remit and denial operations with synthetic data only.

It is not a payer contract analysis, legal opinion, medical coding authority, compliance certification, or production posting system.

The included 835 preview, remit lines, payer names, trace numbers, CARC/RARC mappings, workqueues, audit events, and metrics are synthetic implementation proof artifacts. They are not production payer files, not client payment files, and not payer-specific companion-guide output.

Production use requires:

- Appropriate agreements before handling live healthcare data.
- Secure file transfer, access control, logging, and retention controls.
- Payer contract and companion-guide review.
- Posting-rule validation with the client's billing system.
- Client approval of denial ownership, appeal thresholds, and write-off rules.
- Compliance review before any live payment, denial, or claim data is processed.
